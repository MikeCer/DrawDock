# Project records

This folder separates project progress, machine-specific discovery and
validation evidence from the [contributor documentation](../docs/README.md).

| Record | Contents |
|---|---|
| [Capability matrix](capability-matrix.md) | Requirement-by-requirement results and evidence gaps |
| [Environment inventory](environment.md) | Hardware, tools and device observations |
| [Implementation plan](implementation-plan.md) | Windows-first milestones and acceptance criteria |
| [Feasibility report](feasibility-report.md) | Implementation history, experiments, measurements and acceptance work |
| [Brand adoption](brand-adoption.md) | Owner-gated branding milestones and review checklist |

These are point-in-time records. Earlier sections can contain historical test
counts, configurations and behavior; use the technical guides and source for
the implementation contract. Preserve dates and distinguish automated checks,
synthetic input, framebuffer sampling and physical device/display observations.

Keep new progress reports and validation results here rather than in `docs`.
Do not include credentials, QR payloads, private keys or sensitive captures.
